# Automation Engineer — Learning Journey

> Your path through the AI Center of Excellence. 8 shared modules to build Copilot mastery, then 4 role-specific modules to build your AI automation and pipeline toolkit.

## How This Works

Each module has a prompt file that walks you through a hands-on challenge. Complete the challenge, save your work, and check the box. Your outputs accumulate in `personas/automation-engineer/workspace/` — by the end, you'll have a complete AI pipeline and automation toolkit.

**Your agent**: `@automation-engineer` — invoke it anytime for role-specific guidance.

## Tips for Automation Engineers

- **Module 02 (Platform Inventory)** — document every system you integrate with. This becomes your pipeline dependency map.
- **Module 04 (Prompt Engineering)** — build prompts for: pipeline generation, Dockerfile creation, Terraform module scaffolding, runbook drafting, and incident post-mortem analysis.
- **Module 05 (Agent Design)** — consider building a "pipeline troubleshooter" agent that reads logs and suggests fixes, or a "runbook generator" that turns incident notes into operational procedures.
- **Module 07 (Integration Patterns)** — your bread and butter. Map every data flow, API connection, and file transfer you maintain.
- **Your capstone** (Module 08) produces a complete **AI Pipeline Architecture** for one use case, from data ingestion through model serving, with monitoring and validation documentation.
