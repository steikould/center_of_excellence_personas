## Quality Standard

Every artifact should be:
- Production-oriented — designed for real operational use, not academic exercises
- Specific to animal pharmaceutical context and validated infrastructure
- Complete with error handling, monitoring hooks, and GxP considerations
- Runnable or directly adaptable — code templates should work with minimal modification
