# Co-op — Prompt Library

> Save your reusable prompt templates here as you learn to write better prompts in Module 04.

## Naming Convention
`{task-description}.prompt.md`

Examples:
- `summarize-artifact.prompt.md`
- `explain-term.prompt.md`
- `draft-knowledge-entry.prompt.md`

## Prompt Template Format

Each prompt file should start with:

```markdown
---
Prompt: [Name]
Use case: [When to reach for this]
Variables to fill: [list them]
Context to attach: [#file / #selection / #codebase]
---
```

## Suggested Prompts to Build

These are prompts that would be especially useful for a co-op's daily work:

| Task | When You'd Use It | Why It Helps |
|------|-------------------|-------------|
| Summarize an artifact | When reading a knowledge base entry and want to check your understanding | Turns reading into active learning |
| Explain a term | When you encounter jargon or an unfamiliar concept | Faster than searching, and you can customize the explanation level |
| Draft a knowledge entry | When making a contribution to the knowledge base | Ensures you follow the schema correctly |
| Compare two things | When trying to understand the difference between platforms, approaches, or roles | Builds analytical thinking |
| Ask a persona question | When you want to understand another role's perspective | Simulates the shadowing experience |
| Prepare meeting notes | When attending a CoE meeting and want to capture key points | Develops professional documentation skills |

## Tips for Good Prompts

As you build your library, remember:
- **Be specific**: "Explain LIMS" is okay. "Explain what LIMS is, what data it stores, and why a data scientist would care about it" is better.
- **Include your context**: Tell Copilot you're a co-op at an animal pharma company. It changes the response.
- **Ask for the format you want**: "Give me a table" or "explain in 3 bullet points" gets you usable output faster.
