# Co-op — Custom Agents

> Save your custom agent definitions here as you build them in Module 05.

## Naming Convention
`{agent-name}.agent.md`

Examples:
- `term-explainer.agent.md`
- `artifact-reviewer.agent.md`
- `meeting-notes-helper.agent.md`

## Agent Ideas for Co-ops

Building an agent is a great way to learn how AI assistants work under the hood. Here are some ideas:

| Agent | What It Does | Why It's Useful |
|-------|-------------|----------------|
| **Term Explainer** | Takes any industry term and explains it at three levels: simple, intermediate, and detailed | Your personal glossary companion |
| **Artifact Reviewer** | Reviews your draft knowledge base contributions against the schema | Catches gaps before you submit |
| **Meeting Notes Helper** | Takes rough meeting notes and formats them into structured summaries with action items | A skill you'll use your entire career |
| **Shadowing Guide** | Helps you analyze artifacts from other personas and write better summaries | Makes CO-02 more productive |
| **Connection Finder** | Given two knowledge base entries, identifies how they relate | Builds systems thinking |

## How to Build an Agent

See Module 05 (`.github/prompts/shared/05-agent-design.prompt.md`) for the full guide. Don't worry if your first agent is simple — that's the point. A focused agent that does one thing well is better than a complex one that does everything poorly.

**Quick tip**: Start by thinking about a task you repeat. If you've asked Copilot the same kind of question more than 3 times, that's a good candidate for an agent.
