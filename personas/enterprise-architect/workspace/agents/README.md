# Enterprise Architect — Agents

Custom Copilot agents you build during Module 05 and beyond. These are specialized AI teammates for your architecture workflow.

## Ideas for Agents

- **ADR Writer**: Takes a brief decision description and produces a full architecture decision record
- **Integration Reviewer**: Analyzes a proposed integration and flags anti-patterns, compliance gaps, and missing monitoring
- **Technology Radar Updater**: Evaluates a technology against your standards and recommends a radar classification
- **Graph Query Designer**: Takes a business question and translates it into a knowledge graph traversal pattern

## How to Use

Invoke your agents with `@agent-name` in Copilot Chat. For agents with cross-team value, copy them to `.github/agents/` so others can use them too.
