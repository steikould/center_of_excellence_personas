# Enterprise Architect — Prompts

Reusable prompts you create during your journey. These are your personal prompt library for architecture work.

## Suggested Prompts to Build

As you progress through the modules, consider saving prompts for:

- **System inventory**: Quickly document a new platform using the schema
- **Integration review**: Analyze an integration for anti-patterns
- **ADR drafting**: Generate architecture decision records from a brief description
- **Technology assessment**: Evaluate a new technology against your standards
- **Compliance check**: Review an architecture proposal for regulatory gaps

## How to Use

Reference these prompts in Copilot Chat with `#file:personas/enterprise-architect/workspace/prompts/{prompt-name}.md` to reuse them across sessions.
