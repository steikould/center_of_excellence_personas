## What Goes to the Knowledge Base

Some of your artifacts should also be contributed to `knowledge-base/`:

- **Platform entries** for data systems (LIMS, ML platforms) go to `knowledge-base/platforms/`
- **Best practices** for model development go to `knowledge-base/best-practices/by-role/`
- **MLOps patterns** go to `knowledge-base/best-practices/by-technology/`
- **Model governance** artifacts go to `knowledge-base/governance/`
- **Data integration patterns** go to `knowledge-base/connections/`
