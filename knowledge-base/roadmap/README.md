| Phase | Status | Description |

| [Phase 2 — Batch Integration](phase-2-batch-integration.md) | Planned | Weekly downloads from data governance, other groups, regulatory |
| [Phase 3 — Real-Time Graph](phase-3-realtime-graph.md) | Vision | Live graph database spanning the organization |
